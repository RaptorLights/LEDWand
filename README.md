# LED-Wand Testvideo

Browser-Tool zum Erstellen von Testvideos für LED-Wände: Eine Figur (Bauarbeiter, Stagehand oder Hund) trägt die Module einzeln ins Bild, Farbe für Farbe.

## Funktionen
- Wand-Editor mit gemischten Modulgrößen (px), Block-Einfügen, Drag & Drop
- Testbild pro Modul: Checker, Rahmen, Beschriftung C/R, Diagonalen, Kreis, Auflösung
- Logo-PNG mit Größe, Position und Effekt (Leuchten, Kontur, Schatten, Platte)
- Figuren: Bauarbeiter, Stagehand, Beagle, Golden Retriever, Dalmatiner
- Optionaler Loop: Module werden am Ende wieder abgebaut
- Export als MP4 (H.264, im Browser kodiert) und PNG-Standbilder pro Farbe
- Layout als JSON speichern / laden

## Benutzung
`index.html` im Browser öffnen (aktuelles Chrome oder Edge empfohlen) oder über GitHub Pages bereitstellen.
Alles läuft lokal im Browser, es werden keine Daten hochgeladen.
